# ai-starter-course

A free, self-paced AI course for people who are not technical, run by your AI assistant as an agent skill. In eight weeks it explains how AI and LLMs work in plain words (tokens, parameters, weights, GPUs), walks through today's tools for images, voiceovers, video and slides, shows how to use Claude or ChatGPT in daily life and at work, builds nine everyday agents with you, and ends with a website you vibe code and put online. You get a fixed weekly schedule and Week 1 straight away; each later week comes with exercises, a weekend challenge, a short quiz and a badge when you say you're ready.

```
npx skills add arm-pz/ai-starter-course
```

Ask it things like:

- "I'm not technical. Run me an AI course so I don't have to buy one."
- "Make me a weekly plan to learn AI basics, with exercises."
- "I want to go from 'what is ChatGPT' to building my own agents."
- "Ready for week 3."

Related: [topic-primer](https://skillsmith.tech/topic-primer/) goes deep on one concept, course-builder designs a course you teach to others, study-system builds a practice routine for a skill you're already learning.

## What you'll make

- A 30-second promo made with AI image, voice and video tools
- A library of 10 prompts you actually reuse
- Nine working agents (morning briefing, meal planner, inbox helper, money tracker, trip planner, reading buddy, habit coach, opportunity watcher, home admin)
- A live website with a link you can share

## Install

**Installer:** `npx skills add arm-pz/ai-starter-course`

**Claude Code (manual):** copy the folder to `~/.claude/skills/ai-starter-course/`, or into `.claude/skills/` in a project.

**Claude apps (web, desktop, mobile):** upload `ai-starter-course.zip` under Settings → Capabilities → Skills.

Then say something like: *"I'm not technical — run me an AI starter course."*

## How it stays current

Tool names, free tiers and prices change every month, so the skill looks them up when it writes each week instead of shipping a list that goes stale. Concepts are written in and fact-checked.
